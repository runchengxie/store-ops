# 平台适配边界

[English](../platform-adapters.md)

store-ops 保留通用运营底座，目前**只启用 eMAG RO adapter**，不保留可重新开启的 Amazon 实现。店铺是账号与市场实例，不为每家店复制适配器。

通用层负责认证、权限、AI 会话、MCP 传输与令牌、通用调度、审批审计、证据存储和状态首页。eMAG adapter 负责接口、字段、凭据、分页、平台校验、费用假设与专属工作流。既有 eMAG 服务仍是小接口后的实现细节，并非先构建覆盖所有平台的 ERP 模型。

## 通用只读接口

管理员接口位于 `/api/operations`：

- `GET /platforms`：已启用平台、adapter 版本及能力声明。
- `GET /stores`：带来源的店铺引用。
- `GET /stores/{store_id}/overview`：平台、市场、币种、时区、资料版本、来源、时间、覆盖与限制，以及商品/问题/库存计数和采集回执。

注册表只启用 `emag`，其他平台失败关闭。能力区分已支持、不支持、尚未核实；运行是否就绪单独判断。已支持的实现仍可能缺少配置或完整资料。`price_update` 指既有独立、默认关闭的流程，通用只读接口不授予或分发写操作。`/api/emag` 专属接口保留各自的管理员、快照/修订及审批检查。

未知值保持未知，不把 PNK 等平台标识硬套成虚构的通用商品 ID。平台原始字段与投影仍保留在来源资料中。原店铺 ID、快照、CLI 和 `IVYEA_OPS_*` 配置键保持兼容，抽取接口不会改写历史快照。

## 已下线能力

Amazon 专属页面、接口、算法、后台初始化和任务、MCP 处理器、技能及供应商自动配置已移除。旧页面与接口按普通未找到处理。报告、图片和数学工具仅在确有共享消费者时保留。当前产品提示词不再预设 ASIN/BSR 或 Amazon 规则。

既有历史快照、数据库、凭证、未知私有设置值和任务记录保留。仅退休本应用精确管理的 Amazon 技能根目录注册，不删除文件或任意用户目录；默认设置和能力列表不再提供已下线供应商，不改写外部 MCP 私有配置。

任务若明确引用已退休的应用技能或工具标识，会在交给 Agent 前以“能力已下线”失败，原始任务保留。不用关键词猜测任意自然语言意图。独立安装的外部 Agent 和用户私有工具不属于本仓库删除保证范围；store-ops 不再向这些运行时自动配置原 Amazon 集成。

## 未来新增平台

新增真实 descriptor 与最小运营接口，验证账号/市场身份和来源口径，声明实际能力后显式注册。保留来源、完整性与平台扩展。只有落实具体接口白名单、凭据绑定、审批范围、资料版本/实时检查及回读契约后才新增写能力。部分平台使用 HTTP POST 读取，不能只凭动词判断副作用。

## 自动监控暂停控制

概览中的 `control` 包含 `state`（`enabled`、`pausing`、`paused`）、`paused` 和 `revision`。管理员可向 `/api/operations/stores/{store_id}/control` POST `{paused, revision}`；版本过期返回 409。暂停意图按店铺保存在运行数据目录，重启后仍保留。

首页双箭头控制 eMAG 采集与检查任务，也会阻止之后的定时调用开始执行。任务在网络请求边界以及证据、报告发布前检查暂停状态；已经发出的请求可以完成。任务锁释放前显示“正在暂停”，确认释放后才显示“接管已暂停”。状态未知或读取失败不算暂停成功。恢复后允许下一次定时或手动触发，不会立即发起采集。Windows 定时任务定义保持不变；被暂停的调用记录暂停回执并正常退出。

此控制针对自动监控。用户主动发起的对话、离线查看和单独审批的改价流程仍使用各自的控制方式。内部开发版 Demo 只在本地模拟暂停与恢复，不影响真实店铺。
