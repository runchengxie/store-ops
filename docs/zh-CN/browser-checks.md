# 浏览器辅助 FBE 核对

[English](../browser-checks.md)

工作台可以在 API 巡检之外运行固定的只读 FBE 库存页面核对。Edge 遇到验证码或登录失效时，只等待这项浏览器任务。你在 Edge 处理后，点击工作台的“已处理，继续”。系统不会自动通过验证码，也不会确认价格、发送消息、接受合同或修改商品。

## 采集范围

读取器先核对 eMAG RO 导航中的店铺名称，再记录页面可见商品 ID 和可用库存。页面明确标记不可用的数量保留未知；格式含混的数量或缺失的数量单元格转为待核查。成功只代表**当前可见页面已核对**，不代表全部仓库、库龄、销量、费用或结算。浏览器观察与 API 快照分开保存，不覆盖 API 库存总数。工作台显示独立的上次成功时间；后续读取等待时保留旧结果。

当前读取器要求罗马尼亚语库存页面结构。布局未知、店铺不符或快照不完整时转为待核查。它创建带任务标记的检查标签页并尝试复用；登录跳转可能丢失标记，过时的检查页可手动关闭。核对期间避免其他自动化同时操作这个共享浏览器。

## 私有配置

复用已登录的 Edge 扩展桥接 `http://127.0.0.1:8931/mcp`，不要公开暴露。在现有私有后端启动器配置以下环境变量；自动核对时也配置 supervisor 启动器：

- `IVYEA_OPS_BROWSER_STORE_ID`：现有 eMAG RO 店铺的准确 ID。
- `IVYEA_OPS_BROWSER_ACCOUNT`：eMAG 导航中显示的准确店铺名称。
- `IVYEA_OPS_BROWSER_NODE`：Node 可执行文件的绝对路径。
- `IVYEA_OPS_BROWSER_SDK_ROOT`：已安装的 `@modelcontextprotocol/sdk` 包目录绝对路径，内含 `dist/esm/client/index.js`。
- `IVYEA_OPS_BROWSER_AUTO_CHECK=1`：可选。现有 supervisor 的 API 任务成功后，若尚无浏览器任务或上次成功核对已满 24 小时，则安排一次核对。正在等待的任务不会自动重试。

不增加第二个采集调度，也不复制 MCP 令牌。读取器持有短期回环端口 `8932` 作为独占锁，Python 父进程退出后仍能阻止重复读取；该端口不接受命令，随读取器关闭，端口冲突时任务等待。扩展认证由现有桥接负责。浏览器所在机器需已有 Node 和 MCP SDK，这是可选前置条件，不是新增 Python 服务依赖。源码版需保留 `scripts/browser-fbe-reader.mjs` 和对应 contract/lease 模块；冻结打包版必须先包含这些文件才能启用。环境调整后只重启准确识别的后端服务。配置保存在源码和临时 worktree 之外的私有目录。

## 任务记录与恢复

`IVYEA_OPS_DATA_DIR/browser-checks` 保存 SQLite 任务、任务/浏览器独占锁及不可变的标准化观察。不保存原始 MCP 对话、登录令牌或验证码答案。每店铺只有一个 FBE 任务，重复中断合并为同一个记录。版本号拒绝过时的恢复操作，任务锁和浏览器锁避免重复读取。进程重启释放 SQLite 锁，遗留执行记录转为 `needs_review`；排队记录可以明确重新派发。只有固定只读任务允许这种重试，不能用于商品修改或客服消息。

全局暂停阻止派发，最终发布与暂停确认通过控制数据库事务串行执行；它不会即时中断已发出的有限时长浏览器调用。浏览器等待不占 Go 的 API 槽位，浏览器错误不改变已经成功的 API 回执。首版不做自动网络重试循环或外部通知，需在工作台明确重试。可用性仍依赖笔记本、已登录桌面、扩展和平台会话。

管理员认证接口：`POST /api/operations/stores/{store_id}/browser-check`，用 `{}` 创建或重新派发排队任务，用 `{"revision": N}` 恢复或再次核对。概况返回 `browser_check` 和 `browser_check_available`，不返回文件路径或完整观察。所有者可用固定命令 `python -m app.browser_worker STORE_ID TASK_ID` 执行已排队记录，使用同一份私有配置。

未来迁移服务器前，需先处理当前 Windows 凭证依赖，并独立验证账号绑定和部署。迁移 API 调度不能消除网站验证，也不能保证笔记本浏览器持续在线。
