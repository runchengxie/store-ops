# 独立的找货与浏览器工具

[English](../external-tools.md)

需要找货或检查浏览器页面时，由已配置的 Agent 调用独立安装的工具。store-ops 不直接调用相邻的工具目录。应用启动和已导入证据的离线复核均不依赖这两个工具。

## 职责与版本

| 组件 | 负责 | 不提供 |
|---|---|---|
| store-ops | 店铺身份、证据解释、本地记录、审批与审计规则 | 自动找货或内置浏览器执行器 |
| `1688-product-find` | 找货和比价的外部 CLI | 已确认采购成本、采购操作或 eMAG 商品身份匹配 |
| `@playwright/mcp` | 向调用它的 Agent 提供浏览器操作通道 | 业务审批或操作成功的证明 |

[参考清单](../../configs/external-tools.reference.json)记录检查过的找货工具提交和浏览器包版本。应用不读取这份清单，它也不会自动锁定版本或安装工具。检查元数据不等于通过带认证的兼容性测试。每个任务应在本地记录实际源码提交或包版本、Python 或 Node 运行环境及所用工具配置。升级前，在独立任务中核对新版本接口并保留证据，不能把新版本直接当作已记录的基准。

找货源码保持独立检出，使用清单中的提交，或明确记录替代提交。Playwright MCP 使用独立的 npm 安装目录，保留精确依赖版本及锁文件，重新安装时使用该目录的锁文件。仅阅读本文不需要安装依赖或切换源码版本。本次检查的找货源码没有许可证文件，本阶段不复制或分发其源码。

## 本机配置

在私有 Agent 或启动器配置中明确指定工具安装路径。相邻目录名称和当前工作目录不构成发现工具的约定。本阶段不增加 store-ops 环境变量或工具设置。

找货工具负责自己的授权。检查到的技能使用 `ALI_1688_AK`；保留现有权威凭据存储，遵循外部工具的参考说明。不要把凭据复制到清单、命令历史、报告或仓库文件。缺少授权意味着能力不可用，不能编造结果，也不能擅自改用浏览器搜索绕过工具。

浏览器能力需要在调用它的 Agent 中配置独立安装的 MCP 服务，使用私有设置和现有浏览器连接。JSON 模板或辅助目录不会自动注册。保留扩展令牌与浏览器登录状态，不导出 Cookie。已有的持久连接诊断程序是可选工具，不会为 store-ops 注册能力。

## Agent 操作流程

找货遵循[供货研究指引](supplier-research.md)。它是供已配置 Agent 使用的文档，不是另一个自动挂载的 Skill。搜索产生候选；将候选关联到 eMAG 商品、确认实际成本，需要另外记录判断依据。

eMAG 浏览器操作继续遵循现有[价格核验说明](../../skills/emag/price-validation/SKILL.md)。每个任务保持一个 MCP 连接，检查当前工具定义和页面状态，核实卖家、市场和精确商品身份。安装工具或同意本接入方案都不授予平台改动权限。保留精确动作审批、操作前实时核对、选中数量检查和结果回读。超时或结果不明时停止提交，不能自动重放结果不确定的写操作。

## 证据与私有数据

使用已有项目数据配置，见[配置说明](configuration.md)。新 Agent 任务可在已解析的应用数据目录（`IVYEA_OPS_DATA_DIR`）下，按 `external-tools/<task-id>/` 整理文件。这只是手动目录约定，不是新的自动导入器或应用设置。如果项目另有权威证据目录，应使用其明确约定。不能根据临时 worktree 推导永久路径，也不能猜测并新建数据根目录。

保留任务身份、工具提交或版本、查询或授权动作、带时区的观察时间、来源标识、私有原始证据、解释和局限。保存前去除凭据。更新共享 `current` 或 `latest` 指针需要另行协调发布。盘点使用方和保留要求前，现有文件保持原位。

本阶段按文件大小和 SHA-256 核验了本机 2026-11-03 浏览器探索归档中的 33 条清单记录。归档外还有后续浏览器记录。归档完整性不能证明覆盖了全部历史、平台写操作的结果或工具当前可用。没有移动或删除历史记录。

## 后续应用内集成

只有具体应用流程确实需要时，再增加小型供货搜索接入层。连接 UI 或调度器前，先定义结构化输入输出、版本兼容、凭据归属、超时、错误处理及证据导入。业务解释与审批留在 store-ops。源码 vendor、submodule、工具升级及自动注册均需另行决定，见 [ADR-0059](../decisions/0059-independent-external-tools.md)。
