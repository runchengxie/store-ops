# 运营知识与检查

[English](../operational-knowledge.md)

从登录后状态页菜单打开 **运营参考**（Insights）。这个仅管理员可见的次级页面提供本地资料检索、绑定快照的建议、XLSX 预检查和活动贡献利润估算，保持默认首页简洁，不执行平台修改。

## 私有知识索引

所有者在服务端运行环境导入已生成的 JSON 资料包：

```bash
python -m app.emag_knowledge_cli import --library /private/path/library.json
python -m app.emag_knowledge_cli status
python -m app.emag_knowledge_cli search --query "变体"
```

索引存于 `IVYEA_OPS_DATA_DIR/emag/knowledge.sqlite3`。资料包和数据库应保存在仓库外的私有目录。导入先校验大小和结构，再通过事务启用新版本；错误输入保留原版本。旧版本仍可用于追溯引用。导入仅开放所有者 CLI，网页读者不能指定文件路径或导入资料。

检索返回来源标识、哈希、版本、摘录位置、历史资料标签和已知冲突，机器转写另有标记。摘要及要点位置属于生成资料包的位置；原始文本行号不等于 PDF 页码。来源提供页码或时间时应优先引用。检索采用字面子串匹配，并非语义检索，空结果不能证明没有相关指导。只读 MCP 工具 `ivyea_emag_knowledge_search` 提供相同引用，不改变原有通用知识检索。

培训材料是不可信的历史参考，不能授权操作、确定现行税率、费用或合规规则，也不能证明店铺事实。冲突示例必须结合当前账号资料核实。这些操作不会上传原始文档或视频。

## 店铺检查

建议优先呈现已有库存的实际阻碍和缺失检查，不确认未经验证的根因，保留店铺及当前快照标识。

本地上传 XLSX 可进行有限的结构预检查。支持的布局包括机器字段、必填声明及可读表头；未知或有歧义的布局需人工检查。公式、说明页、变体分组不一致会产生复核提示。服务不重新计算工作簿，不联系平台。限制为上传 5 MiB、ZIP 展开 64 MiB、500 个 ZIP 条目、1,000 行商品及 200 条问题。结果不代表 eMAG 接受或合规认证。

活动检查使用当前快照下保存的成本版本及不含 VAT 的报价。成本缺失、过期或额外费用未填写时，结果不完整；允许明确填写零。折扣和优惠券分别估算，只有显式选择时才计算顺序叠加。佣金减免按佣金率的相对下降计算，不作用于售价；补贴单独列为假设。现有按含税价格估算佣金仍只是假设口径。结果需人工复核，不是已结算净利润或活动资格判断。

页面提供英文和简体中文；内部字段及 API 标识不翻译。本功能不新增自动采集，原有暂停控制和计划任务仍生效。
